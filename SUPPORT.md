# Support

Open a repository issue for reproducible bugs and feature proposals. Include the Keyzori version, operating system, deployment method, expected behavior, actual behavior, and sanitized logs. Include the Bun version when running from source.

Community support is best effort. Do not post license keys, root/API credentials, database URLs, user information, or other secrets. Security vulnerabilities must be reported privately according to [SECURITY.md](SECURITY.md).
